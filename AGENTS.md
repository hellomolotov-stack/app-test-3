# Работа с dietcakes.ru

Перед любыми запросами, авторизацией, автоматизацией или изменениями на dietcakes.ru прочитай `docs/DIETCAKES_ACCESS_RUNBOOK.md` и соблюдай порядок работы, ограничения запросов и условия остановки. Он создан по прямому запросу владельца после исследования 20.10.2026.

Для обычных правок бокса используй локальный `assets/dc/hiking-box.js` и штатный выпуск на Vercel в пределах разрешённой задачи. Доступ к WordPress для таких правок не нужен. При первой ошибке доступа или признаках ограничения останови автоматические обращения; не запускай повторы и смену IP для продолжения операции. Изменение настроек защиты и выдача нового доступа не входят в обычную правку страницы.
