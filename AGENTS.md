# Тексты интерфейса

Все подписи, кнопки, статусы, теги и заголовки интерфейса пишем со строчной буквы. Имена людей, названия мест, брендов и аббревиатуры сохраняют свой регистр: «новое письмо Макса», «хайк на Демерджи». Не применяем сплошной lowercase через CSS или к пользовательским текстам: он испортит имена и названия.

# Работа с dietcakes.ru

Перед любыми запросами, авторизацией, автоматизацией или изменениями на dietcakes.ru прочитай `docs/DIETCAKES_ACCESS_RUNBOOK.md` и соблюдай порядок работы, ограничения запросов и условия остановки. Он создан по прямому запросу владельца после исследования 20.10.2026.

Для обычных правок бокса используй локальный `assets/dc/hiking-box.js` и штатный выпуск на Vercel в пределах разрешённой задачи. Доступ к WordPress для таких правок не нужен. При первой ошибке доступа или признаках ограничения останови автоматические обращения; не запускай повторы и смену IP для продолжения операции. Изменение настроек защиты и выдача нового доступа не входят в обычную правку страницы.

# Передача работы между ИИ
Источник состояния каждой правки — GitHub PR и его история. В описании PR фиксируй задачу, реализацию, результаты проверок, что осталось, имя ветки и SHA; добавляй ссылки на Preview и Production, если они есть. В новой сессии сначала читай этот файл, PR и актуальное состояние `main`. Пока PR открыт, продолжай ту же ветку. Не помещай в публичный репозиторий закрытый контекст или секреты.
