# Цифры клуба

`lib/club-metrics.js` пересчитывает хайки, километры и знакомства на сервере при запросе, а не прибавляет значение к прошлому счётчику. Исправления дистанций и отмены учитываются повторно без дублей. Дистанция берётся из тега `6 км`, а не из длины GPX или числа участников.

Хайк учитывается через пять часов после старта по Москве. Без времени старта — в 20:00. Городские, книжные, отменённые, перенесённые события и даты без названия не учитываются. Даты истории посещений и календаря объединяются; подтверждённый исторический хайк не пропадает из-за пустой старой заглушки.

До приложения есть 20 подтверждённых хайков, но нет дистанций по датам. Исторический километраж — 179 км до 01.03.2026 включительно. Он восстановлен из подтверждённого владельцем итога на 08.11.2026: 301 км минус 122 км из тегов 16 хайков календаря. Это агрегат, не выдуманные дистанции отдельных старых маршрутов. Для исправлений этой части потребуется уточнить исторический агрегат; изменения тегов более поздних хайков учитываются автоматически.

Знакомство — уникальная неупорядоченная пара людей, побывавших на одном завершённом хайке. Повторные совместные хайки не создают новое знакомство. Исторические посещения объединяются с записями через приложение. Отмеченные неявки и технический аккаунт поддержки исключаются. Макс учитывается на всех проведённых хайках, как в прежнем счётчике. Это оценка совместного участия, а не подтверждение личного разговора каждого с каждым.

Локации остаются отдельным редактируемым показателем: названия маршрутов и число посещённых мест не взаимозаменяемы.

`GET /api/club-content?metrics=1` возвращает только итоговые числа, без участников. Клиент обновляет их при запуске, возврате в приложение, обновлении списка хайков, сохранении хайка администратором и раз в минуту. Обновление не перестраивает главную и не меняет прокрутку. Ошибка сети сохраняет последние значения. Отсутствующая дистанция завершённого хайка — ошибка расчёта, а не ноль.
