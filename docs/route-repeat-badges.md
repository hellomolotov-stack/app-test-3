# Повторные маршрутные значки

- Один опубликованный значок маршрута на человека; `grants/<id>/dates` содержит уникальные даты прохождения, `count` равен их числу.
- Одна дата не может увеличить счётчик дважды. Автовыдача использует условный PUT с ETag и повторяет конфликтный запрос.
- `notificationAt` задаёт версию нового получения. Более ранняя отметка `achievementSeen` не скрывает новое прохождение; `notificationAt: 0` означает тихую историческую выдачу.
- Особые значки остаются одноразовыми. Три старых маршрутных записи с типом `special` исправляются миграцией по каталогу маршрутов.
- В коллекции, профиле и окне значка отображается ×N; окно содержит все даты прохождения.
